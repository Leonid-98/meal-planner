М Меню
планировщик еды на неделю · макет для обсуждения, не готовое приложение

Зачем

Убрать шаг «подумать, что поесть». Планировать можно хоть один ужин в день — пустые ячейки не мешают. Из плана собирается список покупок на сегодня, завтра, три дня или неделю; в магазине он открывается на телефоне. Ккал и Б/Ж/У считаются из ингредиентов и нужны как справка для внешнего трекера — сам планировщик калории не отслеживает.

≈ нет данных
Приблизительно. У ингредиента нет КБЖУ — блюдо всё равно можно планировать, цифра помечена.
1 · Новый рецепт
  1. Рецепты → «Новый рецепт», название, порций 4.
  2. Ингредиенты по строке: набрать «кур…», выбрать, 600 г.
  3. Нет в базе — «Создать», ввести КБЖУ с упаковки, не уходя со страницы.
  4. Справа ккал и Б/Ж/У на порцию считаются сами. Теги, шаги, сохранить.
2 · Спланировать неделю
  1. Тап по пустой ячейке → выбор блюда.
  2. Борщ на ужин среды, Лёня 1, Аня 1.
  3. Переключатель «и на завтра → обед»: в четверг появляется карточка остатков.
  4. Итоги дня внизу пересчитались.
3 · Магазин
  1. «Покупки» → выбрать период: сегодня, завтра, 3 дня или неделя. Список сгруппирован по отделам.
  2. Дома отметить «есть дома» лишнее.
  3. В магазине с телефона: тап — куплено, уходит вниз.
  4. Дописать кофе и хлеб отдельной строкой.
4 · Скучно думать
  1. «Заполнить неделю»: только пустые ужины.
  2. Правила: не повторять 14 дней, будни — «быстро», можно «на два дня».
  3. Посмотреть предложение, перекрутить пару ячеек.
  4. «Принять» → список покупок готов.
